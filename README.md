# কল চ্যাট — ওয়েবসাইট (ভয়েস ও ভিডিও কল)

ব্রাউজারে চলা কলিং সাইট। `/` ল্যান্ডিং পেজ, `/app` কলিং অ্যাপ। ফোনে "হোম স্ক্রিনে যোগ করুন" দিলে অ্যাপের মতো চলে।

## ফাইল
- `server.js` — ওয়েব সার্ভার ও সিগন্যালিং (কোনো প্যাকেজ লাগে না)
- `index.html` — ল্যান্ডিং পেজ
- `app.html` — কলিং অ্যাপ
- `package.json`, `render.yaml` — ডিপ্লয়ের জন্য
- `e2e-test.js` — স্বয়ংক্রিয় টেস্ট (Playwright + Chrome লাগে)

## নিজের কম্পিউটারে চালানো
```
node server.js
```
তারপর `http://localhost:3000` খুলুন। দুটি ট্যাবে আলাদা নাম দিয়ে ঢুকে কল করুন।

## ইন্টারনেটে লিংকসহ চালু করা (Render, বিনামূল্যে)
ক্যামেরা-মাইকের জন্য HTTPS লাগে। Render নিজেই HTTPS দেয়।
1. GitHub-এ একটি নতুন রিপো বানিয়ে এই ফোল্ডারের ফাইলগুলো আপলোড করুন।
2. render.com-এ সাইন আপ করুন, **New → Web Service** (বা Blueprint) দিয়ে ওই রিপো বেছে নিন।
3. Runtime: Node, Start Command: `node server.js`। (`render.yaml` থাকলে Blueprint নিজেই সব ঠিক করে নেবে।)
4. ডিপ্লয় শেষ হলে `https://আপনার-নাম.onrender.com` লিংক পাবেন। ওটাই আপনার সাইট।

Railway, Fly.io, Koyeb বা যেকোনো Node হোস্টেও একইভাবে চলে। শুধু `node server.js` চালাতে হবে।

নোট: Render-এর ফ্রি প্ল্যানে কিছুক্ষণ কেউ না থাকলে সার্ভার ঘুমিয়ে যায়, প্রথম খোলায় ৩০-৫০ সেকেন্ড লাগতে পারে। ঘুমালে অনলাইন তালিকাও খালি হয়ে যায়।

## কল না লাগলে (TURN সার্ভার)
কিছু মোবাইল নেটওয়ার্ক ও অফিসের ফায়ারওয়ালে সরাসরি সংযোগ হয় না। তখন রিলে সার্ভার লাগে। যেকোনো TURN সেবা (যেমন coturn নিজে চালানো, বা Metered/Twilio-র মতো সেবা) নিয়ে হোস্টে এই এনভায়রনমেন্ট ভ্যারিয়েবল দিন:
```
TURN_URL=turn:your.host:3478,turns:your.host:5349
TURN_USER=...
TURN_PASS=...
```
সাইট নিজে থেকেই সেগুলো ব্যবহার করবে।

## সীমাবদ্ধতা
- অ্যাকাউন্ট নেই, শুধু নাম। যে আগে ঢুকবে নামটি সে পাবে।
- পেজ খোলা না থাকলে কল আসবে না (পুশ নোটিফিকেশন নেই)।
- কল ও চ্যাট সংরক্ষিত হয় না।
- একটি সার্ভার ইনস্ট্যান্সেই চলে (ইউজার তালিকা মেমরিতে থাকে)।
- একে একে দুজনের কল (গ্রুপ কল নেই)।
